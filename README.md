# 📝 Notes App

A simple and responsive Notes App built with **React** and **Tailwind CSS**. Create, edit, save, and delete your notes with data persisted using **LocalStorage**.

## ✨ Features

* ➕ Create new notes
* 💾 Save notes
* 🗑️ Delete notes
* 💽 Persistent data using LocalStorage
* 📱 Responsive design
* 🎨 Clean UI with Tailwind CSS

## 🛠️ Tech Stack

* **React**
* **JavaScript**
* **Tailwind CSS**
* **LocalStorage**
* **Lucide React**

## 💡 How It Works

Notes are managed using React's `useState` hook and automatically saved to the browser's LocalStorage using `useEffect`. This allows notes to remain available even after refreshing the page.
